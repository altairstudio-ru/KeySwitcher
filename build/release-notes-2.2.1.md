## Исправления преобразования текста

- Добавлены проверки свежести буфера, исходного окна и поля ввода перед вставкой.
- Смена языка ввода направляется исходному окну.
- Восстановление буфера после вставки сохраняет доступные форматы, а не только текст.
- Режим «только скопировать» сохраняет результат даже при включённом восстановлении буфера.
- При неудачном копировании программа сообщает о клавише копирования и не вставляет результат.

Для обычных приложений клавиша копирования должна быть Ctrl+C. Если в настройках назначено Ctrl+Shift+C, это может вызывать другую команду приложения; настройте её отдельно.

Добавлена сквозная проверка выделение → копирование → преобразование → вставка, режима без вставки, восстановления буфера и отсутствия выделения. Тест работает только со своим полем и восстанавливает исходный буфер при завершении.
