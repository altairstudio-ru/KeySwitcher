# AltaiR Key Switcher

Исправляет текст, набранный не в той раскладке (RU ⇄ EN). Выделили текст в любой программе — нажали горячую клавишу — выделение заменено правильно прочитанным текстом.

Работает автономно: программа не хранит историю и ничего не отправляет наружу.

Текущая версия: **1.2.0** (номер в окне «О программе», в свойствах exe и в имени установщика синхронизированы).

---

## Возможности

- Конвертация выделенного текста **в обе стороны** (направление определяется автоматически).
- Перевод из буфера обмена без вставки (второй хоткей или пункт трей-меню).
- Переименование файлов и папок по правому клику (ПКМ → «Исправить раскладку в имени»).
- Всплывающая подсказка с результатом и способом отмены (`Ctrl+Z`).
- Окно настроек: смена горячих клавиш и параметров без перезапуска.
- Самопроверка карты раскладок (`--selftest`).
- Работает как скомпилированным `layout-switcher.exe`, так и исходником под AutoHotkey v2.

## Системные требования

- Windows 7 SP1 и новее (x64).
- Для запуска `.ahk`-исходника: [AutoHotkey v2](https://www.autohotkey.com) (≥ 2.0). Для скомпилированного `.exe` AutoHotkey **не нужен**.

## Установка

Рекомендуется установщик: скачайте `AltaiR-Key-Switcher-<версия>-setup.exe`
на странице [Releases](https://github.com/altairstudio-ru/KeySwitcher/releases)
и запустите — права администратора не нужны (установка в текущий профиль).

Мастер установки предлагает:
- запуск программы при входе в Windows;
- пункт меню Проводника «Исправить раскладку в имени» (ПКМ по файлу/папке);
- ярлык на рабочем столе.

Программа ставится в `%LOCALAPPDATA%\LayoutSwitcher`. Для удаления — «Установка и удаление программ».

Ручная установка (portable): скопируйте `layout-switcher.exe` и `config.ini` в одну папку и запустите — в трее появится иконка. Пункт ПКМ в этом случае нужно зарегистрировать самостоятельно (`reg edit`, раздел `HKCU\Software\Classes`).

Иконка в трее — контекстное меню:

| Пункт | Действие |
| --- | --- |
| AltaiR Key Switcher (из буфера) | Конвертировать содержимое буфера обмена |
| Настройки | Окно настроек |
| О программе | Окно «О программе» |
| Выход | Завершить программу |

> При первом запуске программа создаёт `config.ini` с настройками по умолчанию, если файла нет.

## Использование

### Горячие клавиши (по умолчанию)

| Горячая клавиша | Действие |
| --- | --- |
| `Ctrl+Shift+X` (`^+X`) | Конвертировать выделенный текст и сразу вставить исправление |
| `Ctrl+Alt+Shift+X` (`^!+X`) | Конвертировать выделенное и только скопировать в буфер (без вставки) |

Как это работает: программа делает вид, что нажимает `Ctrl+C`, забирает текст, определяет раскладку, конвертирует и вставляет результат. Если фокус окна сменился — вставка не производится, результат остаётся в буфере.

> Если в выделении нет букв или направление не удалось определить однозначно — программа показывает подсказку и не трогает текст.

### Переименование файлов и папок

Пункт «Исправить раскладку в имени» появляется в контекстном меню Проводника
(устанавливается мастером установки, задача «Пункт меню Проводника»). Команда под капотом:

```
layout-switcher.exe --convert-filename "путь\к\файлу"
```

> Если в исправленном имени оказались символы, которые Windows запрещает в именах файлов
> (`@` → `"`, `^` → `:`, `&` → `?`), программа объяснит это в окне сообщения — файл не переименовывается.

### Работа из командной строки

| Аргумент | Действие |
| --- | --- |
| `--convert-clipboard` | Конвертировать содержимое буфера обмена |
| `--convert-filename <путь>` | Исправить раскладку в имени файла/папки |
| `--selftest` | Проверить карту раскладок (число пар и число ошибок) |

## Настройки (`config.ini`)

Файл лежит рядом с программой. Доступен и через окно «Настройки» в трее; изменения применяются сразу.

```ini
[Hotkeys]
Hotkey=^+X          ; основной хоткей: конвертировать и вставить
HotkeyCopyOnly=^!+X ; только скопировать в буфер, без вставки

[Main]
Direction=auto      ; auto — автоматическое определение направления
AutoPaste=1         ; 1 — сразу заменить выделение вставкой
Sound=0             ; 1 — звуковой сигнал при срабатывании
RestoreClipboard=0  ; 1 — вернуть прежнее содержимое буфера после работы
TooltipMs=2500      ; время показа всплывающей подсказки, миллисекунды
CopyKey=^c          ; клавиша «копировать» для чтения выделения
SwitchLayout=0      ; 1 — вместе с текстом менять и язык ввода (RU<->EN)
```

Обозначение модификаторов AHK: `^` — Ctrl, `+` — Shift, `!` — Alt, `#` — Win.

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `Hotkey` | `^+X` | Горячая клавиша: конвертировать и вставить |
| `HotkeyCopyOnly` | `^!+X` | Горячая клавиша: только скопировать |
| `Direction` | `auto` | Направление. Сейчас поддерживается автоматический режим |
| `AutoPaste` | `1` | Вставлять исправленный текст вместо выделения |
| `Sound` | `0` | Звуковой сигнал |
| `RestoreClipboard` | `0` | Восстанавливать буфер обмена после вставки |
| `TooltipMs` | `2500` | Длительность подсказки, мс |
| `CopyKey` | `^c` | Клавиша копирования (менять только при конфликтах) |
| `SwitchLayout` | `0` | Менять язык ввода (раскладку) вслед за текстом: кириллица → русская раскладка, латиница → английская (US) |

Отмена вставки: `Ctrl+Z` в программе, где выполнялась замена.

## Карта раскладок (`layout-map.ahk`)

Файл содержит таблицу соответствия физических клавиш: каждая пара `'EN', 'RU'` описывает латинский символ и тот же знак в кириллице (буквы обоих регистров, цифры, знаки препинания, `ё/Ё`). Обратная таблица строится автоматически.

Логика:
- `DetectDirection(text)` — определяет направление по доле кириллицы/латиницы (порог 65%); возвращает `RU`, `EN`, `none` или `ambig`.
- `ConvertLayout(text, direction)` — заменяет символы по карте; символы вне таблицы не меняются.

Чтобы добавить символ, дополните `US2RU` новой парой ключ-значение. Правки файла применяются при следующем запуске.

## Сборка релиза из исходников

Нужны: [AutoHotkey v2](https://www.autohotkey.com) (содержит компилятор Ahk2Exe), [Inno Setup 6](https://jrsoftware.org/isinfo.php) и [rcedit](https://github.com/electron/rcedit/releases). Версия приложения задаётся в трёх местах: `APP_VERSION` в `src\ui.ahk`, `MyAppVersion` в `build\installer.iss` и метаданные exe (шаг 2) — их нужно поднимать одновременно.

1. Компиляция exe (скрипты `layout-map.ahk` и `src\ui.ahk` встраиваются, рядом с exe они не нужны):

   ```
   "...\AutoHotkey\Compiler\Ahk2Exe.exe" /in layout-switcher.ahk /out layout-switcher.exe /icon icon.ico /base "...\AutoHotkey\v2\AutoHotkey64.exe"
   ```

   > В Git Bash аргументы вида `/in` ломаются MSYS-преобразованием путей — запускайте из `cmd`/PowerShell или с `MSYS2_ARG_CONV_EXCL='*'`.

2. Метаданные файла (свойства Windows: версия, название, издатель):

   ```
   rcedit-x64.exe layout-switcher.exe --set-file-version 1.2.0 --set-product-version 1.2.0.0 ^
     --set-version-string ProductName "AltaiR Key Switcher" --set-version-string CompanyName "Altair Studio" ^
     --set-version-string FileDescription "AltaiR Key Switcher - correction of RU/EN keyboard layout"
   ```

3. Установщик (результат в `dist\`):

   ```
   "...\Inno Setup 6\ISCC.exe" build\installer.iss
   ```

4. Самопроверка карты раскладок: `layout-switcher.exe --selftest` (ожидаются 94 пары и 0 ошибок).

```
├── icons\                — PNG-набор той же иконки (16–256 px), для справки/UI
├── src\
│   └── ui.ahk            — GUI-модуль: окна «О программе» и «Настройки»
├── build\
│   ├── installer.iss     — скрипт установщика Inno Setup
│   ├── run_selftest.ahk  — головная самопроверка карты (для сборки)
│   └── gen_icon.py       — прежний генератор иконки (исторический)
└── dist\                 — готовые установщики (не в git; как и tools\)
```

## Самопроверка

```
layout-switcher.exe --selftest
```

Проверяет карту раскладок в обе стороны и контрольные примеры определения направления. Показывает число пар в карте и число ошибок (ожидается 0).
